# Product Overview

## What is Acme Platform?

Acme Platform is a cloud-based project management and collaboration tool designed for software development teams. It provides tools for task tracking, sprint planning, code review integration, and team analytics.

## Core Features

### Task Management
- Create, assign, and track tasks with customizable workflows
- Drag-and-drop Kanban boards with WIP limits
- Sprint planning with velocity tracking and burndown charts
- Bulk task operations and CSV import/export

### Integrations
- GitHub and GitLab: automatically link commits and pull requests to tasks
- Slack: receive notifications for task updates, mentions, and due dates
- Jira migration tool: import your existing Jira projects in minutes
- Zapier: connect with 3,000+ apps

### Reporting & Analytics
- Team velocity charts
- Cycle time and lead time analysis
- Cumulative flow diagrams
- Custom dashboard widgets
